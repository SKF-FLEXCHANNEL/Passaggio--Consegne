# Passaggio Consegne HMI

Webapp/PWA per registrare anomalie turno su layout interattivo Zona 1, Zona 2 e Zona 3.

## Pubblicazione su GitHub Pages
1. Carica tutti i file nella root del repository.
2. Vai su Settings > Pages.
3. Source: Deploy from branch.
4. Branch: main / root.
5. Apri il link GitHub Pages.

I dati vengono salvati nel browser con localStorage.
